## 视频号网页会话

粘贴 `weixin.qq.com/sph/...` 分享链接后，网页创建一次性后台会话，在当前页面显示腾讯元宝官方微信扫码二维码。扫码完成后，云端普通 Chromium 使用腾讯官方网页当前会话请求解析接口和视频号官方播放接口，再把返回的完整播放源交给网页预览和保存。网站不读取用户电脑 Cookie、不保存微信登录凭据，后台会话最长约 14 分钟并在完成后关闭浏览器。

如果用户没有在页面内完成扫码，或者腾讯只向当前会话返回封面、HTTP 错误或加密源，网页会明确提示失败，不生成推荐视频或伪造下载结果。

## 实现

Netlify 托管网页、解析函数和媒体读取接口。公开抖音作品由服务端普通 Chromium 加载官方页面，读取对应作品的实际播放数据；浏览器直接预览和保存合法媒体源，必要时回退到网站媒体接口。账号 Cookie 不从用户电脑导入，页面不伪造平台登录。

公开单文件播放源可以直接保存。私密、会员、地区受限、加密内容及仅客户端可访问的作品仍取决于平台权限；没有可用媒体时明确显示失败，不返回宣传片、推荐作品、封面或模拟结果。

## 本地与发布

源目录为本项目。`dist` 只含公开网页、图片与浏览器转换引擎；Node 依赖和服务器源文件位于公开目录之外。Netlify 项目沿用原媒体工具的独立站点，不覆盖工作区作品集。

最终公网版本应核验：无扩展的全新浏览器，从输入分享文案到预览、下载的完整过程；保存文件经过 ffprobe 与全文件解码检查。前端模拟接口检查只用于回归，不代替真实平台验证。
