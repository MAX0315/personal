# 黯马AIGC · 原媒体下载助手 v1.8.0

Chrome 侧栏版：粘贴链接、解析、预览、下载和 MP3 转换均从插件操作。视频号解析使用浏览器的正常腾讯网页会话；不运行本地 EXE，不安装证书，不修改系统代理，不读取电脑微信。

## 安装与使用

1. 解压 ZIP，打开 Chrome 扩展管理页 `chrome://extensions`，开启“开发者模式”。
2. 停用旧版扩展，点击“加载已解压的扩展程序”，选择本目录（含 manifest.json 的这一层）。保留此文件夹。
3. 点击工具栏中的插件图标，打开侧栏。底部版本为 v1.8.0。
4. 视频号首次使用：点侧栏的“登录腾讯”，在 Chrome 中按腾讯官网的正常流程登录。侧栏会保留；不需复制 Cookie、下载助手或打开电脑微信。
5. 在侧栏粘贴原分享链接，点“解析”。需要重新登录时，插件会显示登录入口。登录后点“重试当前链接”。
6. 核对预览后点“下载视频”，使用 Chrome 保存对话框和下载列表。图片及 MP3 沿用侧栏中的相应按钮。

## 视频号的浏览器流程

- 优先读取相同官方作品页面上已提供的完整明文媒体，或使用链接中平台正常签发的播放 token。
- 分享短链需要腾讯元宝网页解析服务。插件在正常腾讯页面内发出请求，返回官方视频号播放页后，继续在官方视频号域内读取对应作品的原始播放源。
- 请求使用页面当前会话及页面自有的请求上下文；不会把账号 Cookie、身份请求头或密码复制到插件存储、日志或外部服务器。
- 解析可能临时创建不激活的腾讯页面，完成后清理自己创建且未被用户接管的页面。不会关闭或跳转用户原有页面。
- 下载前校验 MP4 文件头，保存请求完整文件；HTML、JSON、图片封面、需要额外解码的加密流及未合并分片均不会作为视频下载。
- 腾讯接口的登录、正常验证、内容访问限制和地址时效仍适用。只有封面或扫码页不代表存在可下载视频。浏览器“就绪”也不代表账号已登录，登录可用性以真实解析结果为准。

## 验证范围

自动化测试使用模拟腾讯响应和模拟 Chrome API；它们验证解析连接、错误处理、目标匹配、页面清理和下载校验，不能代替真实账号的完整下载。真实网络探测、测试数及尚未完成的验证见外层“发布验证记录.json”。

当前研发环境无法接入用户 Chrome 登录会话。截图作品尚未完成登录后下载与全片解码核验，不应将本包表述为该作品已经实测下载成功。

## 权限及其他功能

保留原有 downloads、tabs、storage、scripting、activeTab、offscreen、HTTP(S) 主机权限，新增 sidePanel。无 cookies、nativeMessaging、代理或证书权限。HTTP(S) 通配权限支持原有跨平台媒体直链；视频号模块不会访问 localhost。

抖音视频与图文、小红书、B 站单文件 MP4 的流程保持原有实现。MP3 使用随包 FFmpeg.wasm 在浏览器本机转换，源文件上限 200 MiB；正常关闭侧栏仍可继续，关闭浏览器会中断。水印状态以实际预览为准。原图保留平台提供的顺序和地址签名。

仅保存你有权使用的媒体。腾讯未提供完整播放源、直播、无法正常访问的作品和未合并的 HLS / DASH 分片不在支持范围。

## 开发与复验

`node --test tests/*.test.cjs`

核心模块：channels-browser.js（正常浏览器会话）、channels.js（官方数据校验）、channels-hook.js（相同页面响应观察）、background.js（解析任务与下载）、popup.*（侧栏）、offscreen.js / audio-worker.js（MP3）。

技术参考：[Chrome Side Panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)、[腾讯网页解析接口的公开上游实现](https://github.com/ltaoo/wx_channels_download/blob/main/pkg/scraper/wxchannels/yuanbao.go)。本包没有分发或执行该项目的本地捕获引擎。
