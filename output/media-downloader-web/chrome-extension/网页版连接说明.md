# v1.8.2 网页兼容插件

保留 v1.8.0 的全部侧栏操作，连接指定网页版；抖音分享链接在公开解析没有媒体时，会自动读取 Chrome 内的目标作品页。

1. 解压本包，打开 Chrome 的 `chrome://extensions/`。
2. 停用旧版同名插件；开启“开发者模式”，加载 `video-origin-downloader-extension`（有 manifest.json 的文件夹）。
3. 在 `https://anma-media-tool-20261012.netlify.app/` 点击“连接插件”。
4. 需要视频号登录时，点击网页上的“登录腾讯账号”，在 Chrome 中正常登录，再回网页解析。
5. 抖音无需提前打开作品：点击解析后，插件会复用目标作品页或自动打开该页。平台如需正常登录或验证，会显示该页；完成后回到网页再次解析即可。请用 Chrome 打开工具网站，其他软件的内置浏览器无法连接 Chrome 插件。

只允许上面这个明确的网站连接，不允许其他网页调用。网页可发起解析、保存及 MP3 任务；正常腾讯账号会话仍留在浏览器中，不复制 Cookie 或密码，不需要本地 EXE。

原图在网页直接解析模式中可打包 ZIP；通过插件连接模式时按原顺序保存为多张图片。PDF 基础说明书对应 v1.8.0，侧栏基本按钮与本版一致；网页版连接方法以本页为准。

连接功能使用正常网页播放会话，不复制 Cookie 或密码。平台要求的正常登录或验证仍需在 Chrome 中完成。视频号的真实账号作品完整下载仍需实际登录后验证。
