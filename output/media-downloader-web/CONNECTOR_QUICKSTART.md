# 原媒体下载助手 v1.8.2 · 网页连接版

网站：https://anma-media-tool-20261012.netlify.app/

## 首次安装

1. 解压整个压缩包。
2. 用 Google Chrome 打开 `chrome://extensions`，开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本包内的 **video-origin-downloader-extension** 文件夹。
4. 回到网站，点击“连接插件”，确认显示 **已连接 · v1.8.2**。
5. 粘贴完整分享文案，点击“解析素材”。

如果已经加载过旧文件夹，请用新版替换原文件夹后在扩展管理页点击刷新，或者重新加载新版文件夹。插件 ID 为 `jmieokljbejfpppioadgppnhfolajoka`，只能连接上面这个网站。

## 抖音解析与下载

公开服务器无法读取播放信息时，插件会打开或复用目标作品的 Chrome 页面。正常加载完成后，插件读取这条作品的播放信息，再返回网页预览。

如果抖音页面要求登录或验证，请在该页面正常完成，再返回工具网页点击“通过插件重新解析”。核对视频标题、内容和时长后点击“保存视频”。

页面中如果显示未连接插件，请使用安装插件的 **Google Chrome** 打开网站；Codex 内置浏览器或其他未安装扩展的浏览器无法调用此插件。
